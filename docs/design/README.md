# Геймдизайн и решения автора

Здесь записано, что за игра, какие решения принял автор и что делать дальше. Как устроен код — рядом, в `docs/` (после задачи И1: ARCHITECTURE, TESTING).

## 1. Где главная версия

Главная версия — этот репозиторий. Документы в проекте claude.ai «Размышления об игре» — копии и промежуточное хранилище: если они расходятся с репозиторием, верен репозиторий.

## 2. Как работаем

- Геймдизайн и механики обсуждаются в чатах проекта на claude.ai.
- Код пишет Claude Code по очереди задач [backlog.md](backlog.md). Если правка меняет поведение игры, документ здесь обновляется тем же коммитом, что и код.
- Чат проекта пишет в репозиторий только документы: решения и планы в `docs/design/` и задачи в `backlog.md`. Коммитит их прямо в `main`, без pull request. Код, `src/`, `test/` и `dist/` чат не трогает.
- Claude Code работает через pull request: ждёт зелёной проверки GitHub и сам сливает в `main`.

## 3. Правило старшинства

Новее документ и позже дата решения — важнее.
