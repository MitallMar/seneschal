# Очередь задач

Сюда записываются задачи для Claude Code: решение принято в чате проекта на claude.ai, текст задачи лежит здесь. Задачи делаются по одной, сверху вниз.

**Как дать задачу Claude Code:** «Сделай следующую задачу из docs/design/backlog.md» (или «задачу И2»).

**Правило для Claude Code:** когда задача сделана, тем же коммитом поставь у неё `[x]`, дату (по Москве) и одну строку итога, и перенеси её в «Сделано». Если сделать не получилось или нужно решение автора, не отмечай её, а допиши под ней «Вопрос автору: …».

**Образец правил и устройства:** игра автора «Тетрадь по схемотехнике» (репозиторий `MitallMar/tetrad-po-skhemotekhnike`): `CLAUDE.md`, `docs/ARCHITECTURE.md`, `docs/TESTING.md`, `.github/workflows/ci.yml`, `src/shelter/balance.js` (ручки), `src/ui/shelter/gym.js` (там это «спортзал»; здесь — эмулятор), `src/shelter/bots.js` и `tools/shelter-*.mjs` (боты и скрипты), `test/shelter/rules.test.js` (тест правил слоёв), `test/e2e/smoke.py` (проверка в браузере). Движок там другой (JS, расчёт схем), переносятся принципы, а не код. Отличие: здесь TypeScript.

- [ ] **И2. Эмулятор совета**
  Прототип становится эмулятором по образцу `gym.js` «Тетради» (там он зовётся спортзалом), устройство ручек — как в эмуляторе натуры (`src/ui/natura.ts`): панель ручек из `KNOBS`, сгруппированная по разделам, изменённые подсвечены; «Сброс»; «Выгрузить» (P) — текст изменённых значений для копирования в чат; «было / стало» (1 / 2) — два набора значений, переключение на ходу. Параметры адреса: `?seed=…&preset=…&lab=1&designer=1`. Заготовки ситуаций (`preset`): враги в совете, засидевшийся писарь, все новички, пустая должность, главный без признания. Горячие клавиши по `event.code`: Space — сезон, F — +5 сезонов, R — заново, D — взгляд дизайнера, Tab — ручки. В «Взгляде дизайнера» у каждого решения в летописи — веса вариантов (из чего сложился выбор). `window.__emu` для автопроверок (restart, season, setKnob, snapshot). Проверка в браузере — раздел `emu`.

- [ ] **И3. Боты совета и скрипты баланса**
  По образцу `bots.js` и `tools/shelter-*.mjs`. Бот — привычки игрока, действует только функциями, которыми пользуется экран: «ничего не трогает», «ставит по годности», «ставит по стремлениям», «переставляет засидевшихся», «говорит со всеми», «даёт наказы», «случайный». `npm run bots -- --seeds=20`: таблица по ботам — доля решений по ведущей оси у членов совета, споры и их исходы, саботажи и жалобы, лояльность, авторитет, стороны. Пары ботов, различающихся одним решением: если пара нигде не расходится — предупреждение «решение пустое». Разброс по семенам: где исход решает удача. **Поиск неординарных решений** (пожелание автора, 18.11.2026): боты гоняют в Node много симуляций; добавить бота-искателя — случайные и перебираемые стратегии на многих семенах, в отчёт попадают те, что заметно лучше привычных ботов или ведут к необычным исходам (например, держать всех в ссоре, но с сильным главным). Снимок баланса `npm run balance -- --save` / `--diff` в `tools/balance.snapshot.json`, коммитится вместе с правкой `balance.ts`.

### Ждут решения автора

- [ ] **Д3. Хозяйство и подать.** Идеи автора 18.11.2026 (записаны в `koncept-2.md`, «Игровой цикл»): припасы и казна должны иметь приход и расход, стороны — влиять на хозяйство, подать Герцогу — «отдельная единица, напрямую не связанная с казной», нужны условия проигрыша. Вопрос автору: подать — это долг на дорожке сезонов (к осени должен N, закрывается серебром или зерном по невыгодному курсу, недоимка съедает терпение Герцога) или что-то другое? После ответа — задача на хозяйство и проигрыш.
  **Предложение Claude Code (18.11.2026), чтобы было с чем спорить:** подать — отдельный «урок» на год, не строка казны. Герцог назначает его в единицах подати к осени; закрыть можно серебром, зерном или людьми (солдаты, работники) по курсам, которые двигают события мира (война — нужны люди, голод — зерно дороже). Не закрыл — недоимка переходит на следующий год с надбавкой и съедает терпение Герцога. Приход и расход — каждый сезон: урожай осенью (деревни и староста), пошлины и торг круглый год (купцы и писарь), содержание людей и стражи каждый сезон, зимний расход припасов.
