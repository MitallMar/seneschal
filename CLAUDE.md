# Устав лора «Сенешаля» (ветка `lore2`)

Ветка `lore2` — лор мира игры «Сенешаль», перестроенный 23.11.2026 из ветки `lore` (та заморожена). Кода игры здесь нет, с `main` не сливать никогда. Язык файлов и коммитов русский, даты московские.

Главное правило: **тексты мира — нарративные источники, «копии с копий»**. Расхождения между ними нормальны, их не исправляют и не вычищают. Дорого не проверять: писатель читает нужное и пишет.

## Что где

| Путь | Что |
|---|---|
| `resheniya.md` | решения автора: решено, отвергнуто, открыто. Выше всего. |
| `hronologiya.md` | ось мира на две страницы: циклы, приливы, великие события. |
| `kraya/*.md` | справочники по краям: всё о крае по эпохам. |
| `temy/*.md` | справочники по темам, не привязанным к месту: народы, магия, лабиринты, церкви, деньги, Империя. |
| `tablicy/imena.md` | все имена: `Имя \| кто \| где \| годы \| № \| статус`. |
| `tablicy/sobytiya.md` | события: `год \| где \| что \| № \| статус`. |
| `tablicy/zacepki.md` | зацепки для генератора событий игры: `зацепка \| где \| когда \| №`. |
| `teksty/NN.md` | тексты мира с паспортами; список — `teksty/README.md`. |
| `kanon/` | копии канона v5, глоссария, счёта лет, «Иссолы», «Лабиринтов», «Денег», ответов автора. Главные версии — в проекте claude.ai. |
| `arhiv/` | прежняя картотека (факты, карточки, расхождения, сводки партий). Не пополняется; читать только ради подробности. |
| `tools/iskat.py` | поиск слова во всех формах по текстам и справочникам. |
| `tools/proverka.py` | автоматическая проверка нового текста. |
| `tools/vlit.py` | вливает «Строки для таблиц» из текстов в таблицы и справочники. |
| `zadaniya/` | задания партий (для нового чата). |

Старшинство: решения автора → канон → справочники и таблицы → тексты мира.

## Справочники: формат

Файл края или темы — набор записей. Запись — одна сущность: место, учреждение, род, обычай, существо, вещество, событие-узел. Люди — в `tablicy/imena.md`, в справочник — только заметные лица.

```
### Мост через Вирту
ключи: мост, ваделинский мост, третий пролёт, мостовой сбор
- Империя: …
- Цикл 4, отлив: …
- Нынешний прилив: два пролёта каменные, третий деревянный, чинят каждый год; мостовой сбор берёт его светлость.
спорят: кто строил — «имперский» или «имён не осталось» (№ 73)
тексты: № 12, 33, 73
```

- **ключи** — все имена, прозвища и формы, по которым запись ищут grep'ом.
- **Эпохи** — строки-состояния внутри записи, по циклам счёта лет (`Цикл 4, прилив` и т. п.; «Империя» — Первая Империя, цикл 1; «Нынешний прилив» — цикл 5, с 3200). Пустых эпох не писать.
- **Каждое сведение — в одном месте.** В другом файле — только отсылка: `см. kraya/trakt.md: Девятая`.
- **Коротко:** правила и закономерности, а не перечни; 1–5 строк на эпоху; даты — только когда от них что-то зависит.
- **Пометы:** `[Р]` — решено автором или канон; `[П]` — предложение, ждёт автора; `спорят:` — источники говорят разное. Других помет нет.
- Справочник — до 3–4 тысяч слов; больше — делится по эпохам (`vadela-otliv.md`).

## Как писать текст

1. Прочитать этот устав, «Открыто» в `resheniya.md`, нужные справочники (один-два края и тему) и сделать grep по `tablicy/imena.md` для каждого нового имени. Мелочь — `python3 tools/iskat.py слово`.
2. Написать текст: `teksty/NN.md`, в начале «## Паспорт» (кто, кому, когда, где, о чём, что нарочно неверно, вопросы автору), затем «## Опорные строки» (5–10 строк: что текст вводит нового, с номером абзаца), затем «## Строки для таблиц» (готовые строки, см. ниже), затем «## Текст». Сквозных номеров абзацев в тексте не ставить: «абз. N» считается по порядку абзацев раздела «Текст». Нумерация — только своя у документа (статьи приговора, пункты указа, строки ведомости); письмо, сказка, песня, рассказ — сплошным текстом.
3. Проверка 1: `python3 tools/proverka.py teksty/NN.md` — исправить, что нашла.
4. Проверка 2 (одна): один читатель на всю партию (модель Sonnet — дешевле) сверяет каждый текст только с `resheniya.md` и справочником своего края. Ничего не правит, выдаёт два списка: «грубое» и «вопрос автору». Писатель исправляет грубое одним заходом. Разноголосицу с другими текстами не трогать.
5. Готовый текст — в чат автору. В ветку — только по слову автора.

**Строки для таблиц** писатель пишет сам, пока пишет, — по одной строке, с префиксом:

```
имя: Имя | кто | где | годы | № | статус        (люди; бог: / род: / корабль: / животное: — те же 6 колонок)
событие: год | где | что | № | статус           (только события, от которых что-то зависит)
зацепка: зацепка | где | когда | №
справочник: kraya/x.md | Запись | - Цикл 2, прилив: строка   (важное новое; нет записи — заведётся новая)
```

Годы сквозные, статус — `текст` или `слух`. Вливает их скрипт `tools/vlit.py` — без агента.

**Жанры (правило автора 23.11.2026):** деловых бумаг — рядов, ведомостей, списков, книг записи, указов, приговоров, челобитий, дел, грамот, счетов, наказов, донесений — не больше трети текстов в каждом запросе (из 10 — не больше 3). Остальное — письма, сказания, сказки, песни, плачи, размышления, проповеди, дневники, жития, путевые записки, рассказы очевидцев, летописный рассказ. Помета переписчика на полях не делает текст деловым, а деловая вставка внутри письма — не делает письмо бумагой. Религиозных текстов — храмовых книг и летописцев, проповедей, житий, прений о богах, наставлений жрецам, текстов о богах и чудесах — не больше 15% с округлением вниз (из 10 — не больше 1, из 6 — ни одного); жрец-рассказчик или запись в храме о мирском делом текст религиозным не делают. Таблица задания партии задаёт форму каждого текста и держит обе доли.

**Партия:** один писатель берёт 3–5 текстов (чтение устава и справочников — больше половины его расхода, поэтому тексты на писателя не дробить). Каждую партию — в новом чате: всё нужное лежит в ветке.

Вопросы по канону писатель не решает сам — оставляет автору в паспорте, в готовом для выбора виде:

```
Вопрос: Сколько ярусов у Ржавца?
- (а) Не фиксировать — тексты спорят [рекомендую]: это молва искателей, разведано 11.
- (б) 20–25.
- (в) Около 40.
```

2–3 варианта, рекомендованный — первым, с одной строкой «почему». Координатор собирает вопросы партии и задаёт их автору окнами выбора по 3–4 (у автора всегда есть поле для своего ответа).

После ответа автора:
1. Ответ — строкой в `resheniya.md`; при нужде — поправка справочника.
2. Каждый затронутый текст получает одно из трёх:
   - **исправление** — текст прямо противоречит решению в важном: точечная правка;
   - **доработка** — решение добавляет то, что текст должен отразить: писатель дописывает;
   - **не трогаем** — ничего важного; расхождение источника с решением допустимо (тексты — нарративные источники).
3. Правка и доработка — одним заходом, без новых проверок. Поправить можно всегда и позже.

## Как пополнять после партии (по слову автора)

1. Решения автора по вопросам партии — в `resheniya.md` (и в справочники, если это правило мира); тексты — исправление / доработка / не трогаем.
2. `python3 tools/vlit.py teksty/NN.md … --partiya "шестая, ДД.ММ.ГГГГ"` — вливает строки для таблиц (имена, события, зацепки, справочники), правит заголовки текстов и добавляет их в `teksty/README.md`. Запускать один раз на партию.
3. Коммит и push в `lore2`.

## Правила лора

- **Год** — сквозной: прилив цикла k = 800(k−1)+N, отлив — ещё +400; 3265 — нынешний; год Жилы + 484 = сквозной. Местный счёт — в скобках. Подробно — `kanon/hronologiya-schet.md`.
- **Имена:** тёзки нормальны, но не в одном месте и поколении (~40 лет) и не в одном тексте. Перед новым именем — grep в `tablicy/imena.md`.
- Новое название вводить только после описания того, что им называется.
- Новых народов не придумывать; отвергнутое («Отвергнуто» в `resheniya.md`, раздел 11 канона) не возвращать.
- **Владение Сенешаля** (в марках, на притоке большой реки, южнее озера у кромки леса) изнутри не описывать — это задаёт игра. Округу описывать можно. Шести крупным владениям Иссолы и их родам, воеводе, ставке и ближнему к владению городку имён не давать.
- Канон и документы проекта claude.ai не править без автора. На Google Диск ничего не писать.

## Git

- Коммитить прямо в `lore2`, без pull request (так проверки GitHub не запускаются). Push: `git -c push.negotiate=true push origin lore2`. `push --force` запрещён.
- С `main` не сливать ни в какую сторону. В `main` — только то, что связано с разработкой игры, и только с согласия автора.
- Сообщение коммита по-русски: что изменилось в лоре.

## Как игре брать данные

`git fetch --depth=1 origin lore2`, затем `git show FETCH_HEAD:путь`. Табличные данные — `tablicy/`; справочники разбираются по заголовкам `###` и строкам `ключи:` / эпох. Пока игра читает `lore`; перевод на `lore2` — по слову автора.
