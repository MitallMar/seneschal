# Устав лора «Сенешаля» (ветка `lore2`)

Ветка `lore2` — лор мира игры «Сенешаль», перестроенный 23.11.2026 из ветки `lore` (та заморожена); 24.11.2026 — ядро, карта, журнал решений. Кода игры здесь нет, с `main` не сливать никогда. Язык файлов и коммитов русский, даты московские.

Главное правило: **тексты мира — нарративные источники, «копии с копий»**. Расхождения между ними нормальны, их не исправляют и не вычищают. Дорого не проверять: писатель читает нужное и пишет.

## Что где

| `hronologiya.md` | ось мира: циклы, приливы, великие события. |

Старшинство: решения автора → канон → справочники и таблицы → тексты мира. Решения автора о мире стоят в справочниках с пометой [Р]; что важно всем — в ядре.

## Справочники: формат

Файл края или темы — набор записей. Запись — одна сущность: место, учреждение, род, обычай, существо, вещество, событие-узел. Люди — в `tablicy/imena.md`, в справочник — только заметные лица.

```
### Мост через Вирту
ключи: мост, ваделинский мост, третий пролёт, мостовой сбор
- Империя: …
- Цикл 4, отлив: …
- Нынешний прилив: два пролёта каменные, третий деревянный, чинят каждый год; мостовой сбор берёт его светлость.
спорят: кто строил — «имперский» или «имён не осталось» (№ 73)
тексты: № 12, 33, 73
```

- **ключи** — все имена, прозвища и формы, по которым запись ищут (их видно в карте).
- **Эпохи** — строки-состояния внутри записи, по циклам счёта лет (`Цикл 4, прилив` и т. п.; «Империя» — Первая Империя, цикл 1; «Нынешний прилив» — цикл 5, с 3200; «Всегда» — правило вне эпох). Пустых эпох не писать. Строка эпохи начинается с её названия — по нему карта собирает эпохи записи.
- **Каждое сведение — в одном месте.** В другом файле — только отсылка: `см. kraya/trakt.md: Девятая`.
- **Коротко:** правила и закономерности, а не перечни; 1–5 строк на эпоху; даты — только когда от них что-то зависит.
- **Пометы:** `[Р]` — решено автором или канон; `[П]` — предложение, ждёт автора; `спорят:` — источники говорят разное. Других помет нет.
- **Размер:** справочник — до 25 тыс. знаков (около 4 тыс. слов), чтобы читался одним чтением; больше — делится по эпохам (`vadela-otliv.md`). Размер смотреть `python3 tools/chitat.py ФАЙЛ` (`wc -w` русские слова не считает).

## Как читать

Писатель читает широко — лучшие находки бывают в чужих текстах, — но не тратит вызовы на борьбу с файлами.

1. Устав → `yadro.md` → задание → `karta.md`. Карта показывает весь лор; задание даёт 3–5 отсылок «с чего начать», дальше писатель ищет сам.
2. Записи справочников: `python3 tools/chitat.py --zapis слово` (по заголовку и ключам) или файл целиком — **по одному файлу за чтение**: вывод одной команды обрезается примерно на 30 тыс. знаков, два справочника разом не помещаются.
3. Тексты мира — сначала паспорт и опорные строки: `python3 tools/chitat.py --pasport 24 106`; текст целиком — только если зацепило.
4. Канон, глоссарий, ответы автора — по разделам: `python3 tools/chitat.py kanon/kanon-v5.md` (оглавление с числом слов), затем `python3 tools/chitat.py kanon/kanon-v5.md "3.4"`. Таблицы (`tablicy/`) целиком не читать — только поиском.
5. Мелочь — `python3 tools/iskat.py слово` (все формы). `grep` здесь — ugrep: шаблоны с `\|` и `.{0,60}` падают; искать простым словом или через `iskat.py`.
6. `resheniya.md` не читать (всё нужное — в ядре и справочниках); `arhiv/` — только ради подробности.

## Как писать текст

1. Прочитать нужное по разделу «Как читать»; для каждого нового имени — поиск по `tablicy/imena.md`.
2. **План до письма:** части текста и объём каждой. Объём — в рамках задания; короче нижней границы — можно, если всё сказано; **объём вставками не добирать**.
3. Написать текст: `teksty/NN.md`, в начале «## Паспорт» (кто, кому, когда, где, о чём, что нарочно неверно, вопросы автору), затем «## Опорные строки» (5–10 строк: что текст вводит нового, с номером абзаца), затем «## Строки для таблиц» (готовые строки, см. ниже), затем «## Текст». Сквозных номеров абзацев в тексте не ставить: «абз. N» считается по порядку абзацев раздела «Текст». Нумерация — только своя у документа (статьи приговора, пункты указа, строки ведомости); письмо, сказка, песня, рассказ — сплошным текстом.
4. Проверка 1: `python3 tools/proverka.py teksty/NN.md` (объём, годы позже 3265, слова из `zapret.txt`, имена, уже занятые в таблице) — исправить, что нашла.
5. Проверка 2 (одна): один читатель на всю партию (модель Sonnet — дешевле) сверяет каждый текст только с `yadro.md` и справочником своего края. Ничего не правит, выдаёт два списка: «грубое» и «вопрос автору». Писатель исправляет грубое одним заходом. Разноголосицу с другими текстами не трогать.
6. Готовый текст — в чат автору. В ветку — только по слову автора.

**Сюжет без лекала.** Задание даёт обстоятельства и, для живых жанров, завязку из `zadaniya/zavyazki.md`; писатель вправе уйти от неё к своей. Ходы **не по умолчанию** — их можно брать, но не сами собой, а когда текст без них не стоит: гибель кого-то из своих; зов, тяга вниз, «ушёл и не вернулся»; предательство в своих рядах; «последний поход» и беда на самом дне; находка, переворачивающая всё; чудесное спасение. Люди в текстах — не герои и не злодеи: у каждого свой расчёт.

**Строки для таблиц** писатель пишет сам, пока пишет, — по одной строке, с префиксом:

```
имя: Имя | кто | где | годы | № | статус        (люди; бог: / род: / корабль: / животное: — те же 6 колонок)
событие: год | где | что | № | статус           (только события, от которых что-то зависит)
зацепка: зацепка | где | когда | №
справочник: kraya/x.md | Запись | - Цикл 2, прилив: строка   (важное новое; нет записи — заведётся новая)
```

Годы сквозные, статус — `текст` или `слух`. Колонка «кто» в строке имени — **до 200 знаков** (решение автора 24.11.2026): кто, роль и одна черта, по которой его узнают; без цитат, пересказа судьбы и годов по отрезкам — подробности остаются в тексте. Строка справочника, которая отвечает на открытый вопрос или вводит новое правило, — с пометой `[П]`. Вливает строки скрипт `tools/vlit.py` — без агента.

**Жанры (правило автора 23.11.2026):** деловых бумаг — рядов, ведомостей, списков, книг записи, указов, приговоров, челобитий, дел, грамот, счетов, наказов, донесений — не больше трети текстов в каждом запросе (из 10 — не больше 3). Остальное — письма, сказания, сказки, песни, плачи, размышления, проповеди, дневники, жития, путевые записки, рассказы очевидцев, летописный рассказ. Помета переписчика на полях не делает текст деловым, а деловая вставка внутри письма — не делает письмо бумагой. Религиозных текстов — храмовых книг и летописцев, проповедей, житий, прений о богах, наставлений жрецам, текстов о богах и чудесах — не больше 15% с округлением вниз (из 10 — не больше 1, из 6 — ни одного); жрец-рассказчик или запись в храме о мирском делом текст религиозным не делают. Таблица задания партии задаёт форму каждого текста и держит обе доли.

**Темы (решение автора 24.11.2026) — смешанно:** часть текстов партии закрывает узлы хронологии, которым нужен источник (задание называет узел); остальным задание даёт только эпоху, край и форму, тему придумывает писатель. Шаблон — `zadaniya/shablon.md`.

**Партия:** писатели — Opus 5.5 (`model: opus`), уровень размышления **по жанру** (решение автора 24.11.2026): живые жанры — `effort: max`, деловые бумаги — `effort: high`. Один писатель берёт 3–5 текстов одного уровня (чтение устава и справочников — большая часть его расхода, поэтому тексты на писателя не дробить). Каждую партию — в новом чате: всё нужное лежит в ветке.

Вопросы по канону писатель не решает сам — оставляет автору в паспорте, в готовом для выбора виде:

```
Вопрос: Сколько ярусов у Ржавца?
- (а) Не фиксировать — тексты спорят [рекомендую]: это молва искателей, разведано 11.
- (б) 20–25.
- (в) Около 40.
```

2–3 варианта, рекомендованный — первым, с одной строкой «почему». Координатор собирает вопросы партии в `yadro.md`, «Открыто», и задаёт их автору окнами выбора по 3–4 (у автора всегда есть поле для своего ответа). Отвечать автор может и позже — тексты вливаются с открытыми вопросами.

После ответа автора:
1. Ответ — строкой в журнал `resheniya.md` и в тот же заход: правило мира — в справочник с [Р] (снять [П]), правило для всех или отвергнутое — в `yadro.md`; закрытый вопрос убрать из «Открыто».
2. Каждый затронутый текст получает одно из трёх:
   - **исправление** — текст прямо противоречит решению в важном: точечная правка;
   - **доработка** — решение добавляет то, что текст должен отразить: писатель дописывает;
   - **не трогаем** — ничего важного; расхождение источника с решением допустимо (тексты — нарративные источники).
3. Правка и доработка — одним заходом, без новых проверок. Поправить можно всегда и позже.

## Как пополнять после партии (по слову автора)

1. Решения автора по вопросам партии — как выше; вопросы без ответа — в «Открыто» ядра.
2. `python3 tools/vlit.py teksty/NN.md … --partiya "шестая, ДД.ММ.ГГГГ"` — вливает строки для таблиц (имена, события, зацепки, справочники; номер текста — в строку «тексты:» записи), правит заголовки текстов, добавляет их в `teksty/README.md` и пересобирает `karta.md`. Запускать один раз на партию.
3. Коммит и push в `lore2`.

## Правила лора

Правила мира, отвергнутое и открытое — в `yadro.md`. Здесь — правила письма.

- **Год** — сквозной: прилив цикла k = 800(k−1)+N, отлив — ещё +400; 3265 — нынешний; год Жилы + 484 = сквозной. Местный счёт — в скобках. Подробно — `kanon/hronologiya-schet.md`.
- **Имена:** тёзки нормальны, но не в одном месте и поколении (~40 лет) и не в одном тексте; похожих имён у героев соседних текстов одной эпохи избегать. Не злоупотреблять именами одного склада — «-ай-/-ей-/-эй-» с «р», «в», «с» и гласной на конце (Мейра, Кайра, Сейра, Майсэ): у писателей к ним склонность (замечание автора 24.11.2026); `proverka.py` их подсвечивает. Перед новым именем — поиск по `tablicy/imena.md`.
- Новое название вводить только после описания того, что им называется.
- Новых народов не придумывать; отвергнутое не возвращать.
- **Владение Сенешаля** изнутри не описывать — это задаёт игра. Округу описывать можно.
- Канон и документы проекта claude.ai не править без автора. На Google Диск ничего не писать.

## Git

- Коммитить прямо в `lore2`, без pull request (так проверки GitHub не запускаются). Push: `git -c push.negotiate=true push origin lore2`. `push --force` запрещён.
- С `main` не сливать ни в какую сторону. В `main` — только то, что связано с разработкой игры, и только с согласия автора.
- Сообщение коммита по-русски: что изменилось в лоре.

## Как игре брать данные

`git fetch --depth=1 origin lore2`, затем `git show FETCH_HEAD:путь`. Табличные данные — `tablicy/`; справочники разбираются по заголовкам `###` и строкам `ключи:` / эпох. Пока игра читает `lore`; перевод на `lore2` — по слову автора.
