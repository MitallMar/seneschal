# Канон по разделам

Канон мира «Сенешаль» собирается заново по разделам (решение автора 24.11.2026): каждый раздел — отдельный файл до 25 тыс. знаков, читается одним чтением. Главная версия — здесь, в ветке `lore2`; в проект claude.ai идут копии утверждённых разделов. После каждого решения автора правится нужный раздел — версий больше нет.

Канон — законы мира и «почему так»; «что, где и когда» (места, роды, учреждения по эпохам) — в справочниках `kraya/`, `temy/`. Правила, которые нельзя нарушать, отвергнутое и открытое — `yadro.md`.
