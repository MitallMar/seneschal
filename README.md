# Сенешаль — прототип характеров и совета

Проверка главной системы Концепта 2 («Kingmaker наоборот»): читаются ли персонажи как личности, когда совет решает дела без Сенешаля.

**Играть:** скачать [`dist/index.html`](dist/index.html) и открыть в браузере. Это один файл, установка и сеть не нужны.

## Что уже есть
- **Звезда склонностей** из пяти осей: Долг, Выгода, Забота, Дерзость, Обычай.
- **Прогон предыстории**: черта и метка заданы автором, звезда, биография, стремление и личные связи складываются из 6 случайных событий.
- **Совет** из пяти должностей (староста, десятник, ключник, писарь-казначей, лесничий), главный на время отлучки.
- **Отношения** между членами совета: «заодно / ладят / терпят / соперники / враги», исходы споров (сошлись, рассудил главный, компромисс, продавил, саботаж, жалоба).
- **Опыт** с потолком (новичок → освоился → мастер), **«засиделся»**, **стремления**, **перестановки за авторитет**, **наказ**, медленный **дрейф** характера.
- **Знание о людях**: сразу видны имя, возраст, должность, метка и одна вещь — молва (бывает неверной) или черта. Разговоры открывают по порядку черты, стремление и склонности словами («сильно / заметно / слабо»); решения в деле открывают склонности без разговоров. Скрытые черты («Хитрый», «Злопамятный») выдаёт только поступок; скрытный в первом разговоре о главном молчит, но сразу рассказывает о стремлении. Годность к должности — словом, мнение главного — с пристрастием. «Взгляд дизайнера» показывает настоящие числа.
- **Черты в течение жизни**: к ключевой черте человек наживает до трёх — из привычки («Прижимистый», «Сердобольный», «Чтит старину»), из отношений («Злопамятный к …» после саботажа); должностные черты («Мастер своего дела», «Оброс связями», «Устал от службы») в этот предел не входят и снимаются через сезон после ухода с должности; новая черта видна сразу, кроме скрытых; перелом («Ожесточился», «Стал набожен») — заготовка без событий-поводов.
- **Должность и характер**: у каждой должности 2–3 родные склонности — её события задевают их часто, остальные изредка; на своём месте человек решает по-своему в четырёх случаях из пяти, на чужом — меньше чем в половине. 30 событий совета; у каждой склонности есть цена, лес больше не копит одни плюсы. Таблицы — `npm run axes`.
- **Генератор натур** (отдельно от совета, в игру пока не подключён): 12 признаков, 30 натур, мешок из 84 черт и перков; древо черт растёт от якорей ядра и одного дальнего, с обязательным противоречием. Отчёт `npm run natura`: рероллы одной натуры похожи на 0,17, натура угадывается по чертам в 69% случаев.
- **Эмулятор натуры** — вторая страница, `dist/natura.html` (ссылка «Эмулятор натуры →» в шапке прототипа): прогон рероллов, метрики с целями, цветные графики, человек с древом черт, таблицы всего наполнения (натуры, мешок, признаки) и ручки, которые действуют сразу.
- **Приключенцы** (галочка «Лабиринт открыт») — события, задевающие две сферы сразу.
- **Ручки баланса**: все числа совета лежат в `src/sim/balance.ts`, у каждого диапазон, шаг и подпись — заготовка под ползунки эмулятора.
- **Проверки**: тесты логики (одно семя — одна партия, перестановки, исходы споров), проверка прототипа в настоящем браузере, проверка на GitHub на каждый pull request.

## Что будет дальше
Очередь задач — [docs/design/backlog.md](docs/design/backlog.md).
- **Мешок по трём происхождениям** (И9): врождённое, нажитое до игры и в игре; одна система черт с советом.
- **Здоровье** (И10): крепость, болезни, смена людей на должностях.
- **Генератор событий мира** (И11, ждёт решения по подати): слои-шестерни от мира до баронства.
- **Эмулятор совета** (И2): панель ручек баланса с «было / стало», заготовки ситуаций (враги в совете, засидевшийся писарь, пустая должность), горячие клавиши, веса вариантов у каждого решения во «Взгляде дизайнера».
- **Боты совета и скрипты баланса** (И3): привычки игрока как боты, таблицы по прогонам, поиск «пустых» решений, снимок баланса.
- **Ждёт решения автора**: хозяйство и подать Герцогу, условия проигрыша (Д3).
- Позже, когда появится игра, а не прототип: сохранения, режим мастера, сборка для тестеров.

## Как играть
Ссылка — вверху. Из клона репозитория: открыть `dist/index.html` в браузере (двойным щелчком, сервер и сеть не нужны). Замысел игры — [docs/design/koncept-2.md](docs/design/koncept-2.md).

## Как устроено
```
src/data/   — данные: оси, черты, метки, должности, стремления, предыстории, события
src/sim/    — ядро без экрана: генерация, решения, совет, сезоны; balance.ts — числа баланса, rng.ts — случайность с семенем
src/ui/     — страница прототипа
tools/      — сборка в один HTML, прогон без экрана, проверка длины строк
test/       — тесты логики и проверка в браузере (test/e2e/smoke.py)
dist/       — собранные страницы: index.html (прототип совета) и natura.html (эмулятор натуры)
docs/       — design/ (замысел, решения, очередь задач), ARCHITECTURE.md, TESTING.md
```
Зависимости идут в одну сторону: `src/ui` → `src/sim` → `src/data`. Подробно — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md); как проверять — [docs/TESTING.md](docs/TESTING.md); правила работы над проектом — [CLAUDE.md](CLAUDE.md).

## Команды
```
npm install
npm run check        # всё разом: типы, линтер, тесты, сборка — после любой правки
npm run build        # собрать dist/index.html (один файл, открывается в браузере)
npm test             # тесты логики
npm run lint         # линтер и длина строк
npm run e2e          # проверка собранного прототипа в браузере (нужны Python, пакет playwright и Chrome)
npm run e2e -- --list            # разделы браузерной проверки; npm run e2e -- staff — один раздел
npm run sim -- семя 12 [--log]   # прогнать 12 сезонов без экрана и вывести сводку
npm run natura -- --rolls=1000 [--save] [--diff]   # отчёт генератора натур: метрики, предупреждения, пять примеров
npm run axes                     # отчёт: должность × склонность по событиям, плюсы и минусы склонностей, прогон 20 семян
```
