# Сенешаль

RPG о маленьком месте и его людях. Сенешаль растит выморочную марку на кромке Великого леса чужими руками, платит за каждое решение доверием, временем или людьми и видит, как место меняется вместе с ним. Развитие места — ось игры, а не хаб; управление непрямое, через решения и людей.

**Играть прототип:** скачать [`dist/index.html`](dist/index.html) и открыть в браузере — один файл, установка и сеть не нужны. Вторая страница — эмулятор натуры, [`dist/natura.html`](dist/natura.html).

## Замысел — Концепт 3

- **Где и кто.** Выморочное баронство в полосе марок Иссолы, восточного герцогства Тервины, у самой кромки Великого леса. Сенешаль — управитель, которого поставила палата. Над маркой — герцог, палата и воевода; вокруг — соседи по Талице. Антагонист — Ратша, проситель из соседнего рода: метит на ту же марку.
- **Испытание первого акта.** За три года обжить марку и платить: дворов — до нужного числа, острог исправен, храм с жрецом, смотр без недоимки, повышенная подать в срок. Провал — не конец: марку отдают просителю, её можно вернуть.
- **Ось — место и дворы.** 10–15 мест со ступенями от «брошено» до «крепко»; жилые дворы — главный счёт. Люди вольные: приходят на льготу и землю и уходят, когда негде спрятаться или суд неправый.
- **Время.** Ход — месяц из трёх декад; за месяц у Сенешаля три дела, внутри каждого — эпизоды и решения. Совет собирается в начале месяца.
- **Люди.** Каждый — на движке характеров: натура, весы решения (желания и удержки), подход — чем его взять, и память — что помнит и что прощает. Совет из набольших решает дела и без Сенешаля, по своим натурам. Баронство живёт целиком, несколько сотен человек, тремя кругами подробности: ближние, видные и строки дворов.
- **Скрытая жизнь и следы.** Все события идут одним движком: личные, должностные, пересечения, стол Сенешаля. У людей тянутся **нити** — линии судьбы со ступенями: долг, любовь, прошлое. Изнутри давит **лихо** — преступность, снаружи — **кромка**, натиск зверя. Игрок видит не скрытое, а его следы: молву, доклады с пристрастием, свои уши в замке.
- **Внешние силы** — палата и герцог, Ратша, соседи; во втором акте гильдия. Ходят тонко, через агентов и следы.
- **Акты.** Первый — обжить (три года); второй — устье лабиринта у старой шахты (пять-шесть лет); третий — открыт.

### Для Концепта 3 — в коде
- **Генератор натур**: 12 признаков, 31 натура, мешок из 188 черт и перков (И27в, И27г): пороки и тайны, добрые нити, облик, умения под места и дела, мешок Сенешаля; у человека 1–2 врождённые черты, нажитые до игры и в игре, происхождение («Откуда и чей») и у трети — черта облика; сошедшиеся черты и признаки дают сплав («Тихий омут», «Весёлый вор»). Рероллы одной натуры похожи на 0,08, натура угадывается по признакам в 92% случаев. Отчёт — `npm run natura`, подробно — [natura.md](docs/design/natura.md).
- **Портрет по Концепту 3** (И27а–И27е): видно, чего человек хочет и что его удерживает, чем его взять и чем нельзя, что он помнит, как говорит и искажает доклад, с кем ладит, чем виден со стороны, какие нити судьбы открывает и где его дело идёт лучше. Складывается из двенадцати признаков и особенного черт и перков мешка; у каждой строки видно, от признака она или от какой черты. Новые черты и слои — задача И27в; словарь нитей, роль «свидетель» и черты «Знавал лучшие дни» и «Скрывает вину» по каталогу нитей — И27г. Происхождение ложится в портрет как слабая черта; его доли зависят от места (деревня, замок, приём пришлых); у Сенешаля — одно из четырёх происхождений (И27д). В словаре 30 нитей каталога, предложенных нет (И27е).
- **Колода событий** (И28, И28а): первая пачка — 40 карточек и 124 варианта данными, у каждого варианта метка и исход: уровень, место, время, роли-слоты, варианты с метками «кому по душе» из словаря портрета, исходы (серебро, дворы, слово Сенешаля, отношения, лихо), следы по каналам. Движка событий ещё нет. Подробно — [koloda.md](docs/design/koloda.md), раздел 6.
- **Здоровье**: крепость, 21 черта здоровья, проверка раз в сезон; срок жизни обычный — старость с 50, предел около 85, за 20 лет партии выбывает 57% людей. Отчёт — `npm run health`, подробно — [zdorovye.md](docs/design/zdorovye.md).
- **Мешки имён**: основа, славянский оттенок крестьян марок, прозвища, мешки пяти народов; тёзок в одном месте и поколении нет. Подробно — [imena.md](docs/design/imena.md).
- **Эмулятор натуры** — `dist/natura.html`: прогон рероллов, метрики с целями, графики, человек с древом черт и портретом, таблицы наполнения, ручки.

К совету прототипа натура, портрет, здоровье и имена пока не подключены.

### Прототип по Концепту 2 — играть
Это проверка главной системы Концепта 2: читаются ли персонажи как личности, когда совет решает дела без Сенешаля. Концепт 3 берёт из прототипа характеры, совет без Сенешаля, «под чужой рукой», генератор мира, ботов и ручки (`koncept-3.md`, раздел 15).
- **Характеры и совет**: звезда из пяти склонностей (Долг, Выгода, Забота, Дерзость, Обычай), прогон предыстории, совет из пяти должностей и главный на время отлучки, отношения и исходы споров, опыт и «засиделся», стремления, перестановки и наказ за авторитет, черты в течение жизни, знание о людях через разговоры и поступки — [koncept-2.md](docs/design/koncept-2.md).
- **Должность и характер**: у должности 2–3 родные склонности, 38 событий совета — [dolzhnost-i-harakter.md](docs/design/dolzhnost-i-harakter.md).
- **Люди решают исходы**: сила дела — мастерство × опыт × настрой, свой почерк у каждой склонности на каждой должности, засидевшийся — сильный, но своевольный — [lyudi-i-ishody.md](docs/design/lyudi-i-ishody.md).
- **Хозяйство и подать**: люди, еда, товары, серебро; шесть сторон с зонами доверия; год по сезонам; ведомость и прогноз; курс на сезон; урок подати и способы платить, сборщица, терпение Герцога — [hozyaystvo.md](docs/design/hozyaystvo.md).
- **Авторитет**: опора каждый сезон, потолок, подать в срок, жалобы, пиры, приказ против мнения советника — [avtoritet.md](docs/design/avtoritet.md).
- **Порядок**: шкала «вольно ↔ строго» из пяти ступеней, стража, гниль при строгой руке, удачи дозора — `hozyaystvo.md`, раздел 8.
- **Кризисы и падение**: кризис стороны и шрам; баронство отдают другому — Сенешаль «под чужой рукой» с бароном и свитой, и марку можно вернуть — `hozyaystvo.md`, разделы 9–10 и 16.
- **Мир вокруг**: состояния герцогства на годы, погода года, указы Герцога, совет отвечает на беду — `koncept-2.md`, «Генератор событий мира».
- **Эмулятор**: вкладки, сводка и летопись, ручки баланса (Tab), «было / стало», девять заготовок ситуаций, «Взгляд дизайнера» с настоящими числами.
- **Боты и бот-искатель**: привычки игрока играют сотни партий без экрана; пары, различающиеся одним решением; поиск стратегий лучше «Хозяина» — [boty.md](docs/design/boty.md).
- **Проверки**: тесты логики, проверка в настоящем браузере, проверка на GitHub на каждый pull request.

## Как устроено
```
src/data/   — данные: оси, черты, метки, должности, стремления, предыстории, события, хозяйство (стороны, курсы, способы платить подать)
src/sim/    — ядро без экрана: council/ — совет (генерация, решения, спор, перестановки, знание о людях), season.ts — сезон, economy/ — хозяйство и подать, state.ts — состояние партии (типы и чтение), balance.ts — числа баланса, rng.ts — случайность с семенем
src/ui/     — страницы: council/ — прототип совета (панели, эмулятор, точка входа main.ts), natura.ts — эмулятор натуры
tools/      — сборка в один HTML, прогон без экрана, проверка длины строк
test/       — тесты логики и проверка в браузере (test/e2e/smoke.py)
dist/       — собранные страницы: index.html (прототип совета) и natura.html (эмулятор натуры)
docs/       — design/ (замысел, решения, очередь задач), ARCHITECTURE.md, TESTING.md
```
Зависимости идут в одну сторону: `src/ui` → `src/sim` → `src/data`. Подробно — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md); как проверять — [docs/TESTING.md](docs/TESTING.md); правила работы над проектом — [CLAUDE.md](CLAUDE.md).

## Команды
```
npm install
npm run check        # всё разом: типы, линтер, тесты, сборка — после любой правки
npm run build        # собрать dist/index.html (один файл, открывается в браузере)
npm test             # тесты логики
npm run lint         # линтер и длина строк
npm run e2e          # проверка собранного прототипа в браузере (нужны Python, пакет playwright и Chrome)
npm run e2e -- --list            # разделы браузерной проверки; npm run e2e -- staff — один раздел
npm run sim -- семя 12 [--log]   # прогнать 12 сезонов без экрана и вывести сводку
npm run health -- --people=3000 [--save] [--diff]    # отчёт о здоровье: кто выбывает за партию, срок жизни
npm run natura -- --rolls=1000 [--save] [--diff]   # отчёт генератора натур: метрики, предупреждения, пять примеров
npm run bots -- --seeds=100 [--level=4] [--pair=О3] [--lab] [--full]   # отчёт по ботам: таблицы, пары, пустые решения; уровень 4 — перепроверки
npm run seek -- [--random=300] [--top=6] [--no-pairs] [--full]         # бот-искатель: стратегии лучше «Хозяина» и необычные исходы (около трёх минут)
npm run balance -- --diff [--save]                  # снимок баланса: первые строки отчёта ботов и что изменилось
npm run economy -- --seeds=100 [--save] [--diff]    # отчёт о хозяйстве: закрыто ли испытание, чем и с кого платят, недодача
npm run axes                     # отчёт: должность × склонность по событиям, плюсы и минусы склонностей, прогон 20 семян
```
