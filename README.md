# Сенешаль — прототип характеров и совета

Проверка главной системы Концепта 2 («Kingmaker наоборот»): читаются ли персонажи как личности, когда совет решает дела без Сенешаля.

## Что внутри
- **Звезда склонностей** из пяти осей: Долг, Выгода, Забота, Дерзость, Обычай.
- **Прогон предыстории**: черта и метка заданы автором, звезда, биография, стремление и личные связи складываются из 6 случайных событий.
- **Совет** из пяти должностей (староста, десятник, ключник, писарь-казначей, лесничий), главный на время отлучки.
- **Отношения** между членами совета: «заодно / ладят / терпят / соперники / враги», исходы споров (сошлись, рассудил главный, компромисс, продавил, саботаж, жалоба).
- **Опыт** с потолком (новичок → освоился → мастер), **«засиделся»**, **стремления**, **перестановки за авторитет**, **наказ**, медленный **дрейф** характера.
- **Видимость**: звезда размыта, пока Сенешаль не поговорит с человеком. «Взгляд дизайнера» показывает настоящие числа.
- **Приключенцы** (галочка «Лабиринт открыт») — события, задевающие две сферы сразу.

## Как устроено
```
src/data/   — данные: оси, черты, метки, должности, стремления, предыстории, события
src/sim/    — ядро без интерфейса: генерация, решения, совет, сезоны; config.ts — числа баланса
src/ui/     — страница прототипа
tools/      — сборка в один HTML и прогон без экрана
```

## Команды
```
npm install
npm run build        # собрать dist/index.html (один файл, открывается в браузере)
npm run sim -- семя 12 [--log]   # прогнать 12 сезонов без экрана и вывести сводку
npm run check        # проверка типов
```
