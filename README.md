**Состояние на 22.11.2026 — проба.** Всё выписано агентами за один проход по канону (через глоссарий) и 48 текстам, сведено и выборочно сверено с источниками: из 95 случайных строк 89 верны, 6 были неточны и исправлены, ошибок нет; все 305 пересчётов годов в сквозной счёт сходятся. Автором ещё не вычитано. Строки со статусом `текст` — версии внутримировых источников, а не закон мира.

Объём: 528 записей в реестре имён (478 людей), 935 строк хронологии, около 1650 опорных фактов, 273 зацепки, 242 решения автора с отвергнутым и открытым, 48 карточек.
