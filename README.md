# Лор «Сенешаля» — ветка `lore2`

Лор мира игры «Сенешаль», перестроенный 23.11.2026 из ветки `lore` (она заморожена и остаётся архивом; игра пока читает её); 24.11.2026 — ядро, карта и журнал решений. Кода игры здесь нет, с `main` не сливается.

Устав — `CLAUDE.md`: как читать лор, как писать тексты, как пополнять.

## Состав

- `yadro.md` — ядро: правила мира, которые нельзя нарушать, отвергнутое, открытые вопросы.
- `karta.md` — карта лора: по строке на каждую запись справочников (собирает `tools/karta.py`).
- `hronologiya.md` — ось мира: циклы, приливы, великие события.
- `kraya/` — 13 справочников по краям: Вадела, Иссола, полоса марок, тракт, Ржавец, Вирта, Холодная, степь и горы, кромка, Тервина, Кассара, Кадрум, большой мир.
- `temy/` — 7 справочников по темам: народы, магия, лабиринты, гильдия и добыча, церкви, деньги, Империя.
- `tablicy/` — имена, группы звучания имён (`imena-meshki.md`), события, зацепки (таблицы для игры).
- `teksty/` — тексты мира с паспортами; список — `teksty/README.md`.
- `resheniya.md` — журнал решений автора по датам, с источниками.
- `kanon/` — копии канона, глоссария, счёта лет и документов автора.
- `arhiv/` — прежняя картотека: факты, карточки, расхождения, сводки партий.
- `opyty/` — опыты: один текст разными писателями.
- `zadaniya/` — задания партий, шаблон задания, таблица завязок.
- `tools/` — `chitat.py` (чтение по частям), `iskat.py` (поиск во всех формах слова), `proverka.py` (проверка нового текста), `vlit.py` (вливание строк текста в таблицы и справочники), `karta.py` (карта лора), `zapret.txt`.
