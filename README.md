# Лор «Сенешаля» — ветка `lore2`

Лор мира игры «Сенешаль», перестроенный 23.11.2026 из ветки `lore` (она заморожена и остаётся архивом; игра пока читает её). Кода игры здесь нет, с `main` не сливается.

Устав — `CLAUDE.md`: как писать тексты (писатель читает нужное и пишет; две лёгкие проверки), как искать, как пополнять.

## Состав

- `resheniya.md` — решения автора: решено, отвергнуто, открыто.
- `hronologiya.md` — ось мира: циклы, приливы, великие события.
- `kraya/` — 13 справочников по краям: Вадела, Иссола, полоса марок, тракт, Ржавец, Вирта, Холодная, степь и горы, кромка, Тервина, Кассара, Кадрум, большой мир.
- `temy/` — 6 справочников по темам: народы, магия, лабиринты, церкви, деньги, Империя.
- `tablicy/` — имена, события, зацепки (таблицы для игры).
- `teksty/` — тексты мира № 1–78 с паспортами.
- `kanon/` — копии канона, глоссария, счёта лет и документов автора.
- `arhiv/` — прежняя картотека: факты, карточки, расхождения, сводки партий.
- `tools/` — `iskat.py` (поиск во всех формах слова), `proverka.py` (проверка нового текста), `zapret.txt`.

Справочники собраны из прежней картотеки без перечитывания текстов; всего около 51 тысячи слов. Вопросы, возникшие при сборке, — в «Открыто» в `resheniya.md`.
