# Сенешаль — эмулятор совета и хозяйства

Проверка главной системы Концепта 2 («Kingmaker наоборот»): читаются ли персонажи как личности, когда совет решает дела без Сенешаля.

**Играть:** скачать [`dist/index.html`](dist/index.html) и открыть в браузере. Это один файл, установка и сеть не нужны.

**Замысел пересобран 25.11.2026** — [Концепт 3](docs/design/koncept-3.md): ось — место и жилые дворы, ход — месяц из трёх декад, скрытая жизнь владения и следы. Прототип ниже собран по Концепту 2 и ещё не переделан.

## Что уже есть
- **Звезда склонностей** из пяти осей: Долг, Выгода, Забота, Дерзость, Обычай.
- **Прогон предыстории**: черта и метка заданы автором, звезда, биография, стремление и личные связи складываются из 6 случайных событий.
- **Совет** из пяти должностей (тиун, десятник, ключник, писарь-казначей, лесничий), главный на время отлучки. На старте одна-две должности достались от прежних баронов не по годности — по родству, старшинству или милости; кто и почему, видно в летописи и биографии.
- **Отношения** между членами совета: «заодно / ладят / терпят / соперники / враги», исходы споров (сошлись, рассудил главный, компромисс, продавил, саботаж, жалоба).
- **Опыт** с потолком (новичок → освоился → мастер), **«засиделся»**, **стремления**, **перестановки за авторитет**, **наказ**, медленный **дрейф** характера. Годный к должности осваивается быстрее негодного: прирождённый — за два сезона, негодный — за восемь; штраф негодного написан в ведомости словами.
- **Знание о людях**: сразу видны имя, возраст, должность, метка и одна вещь — молва (бывает неверной) или черта. Разговоры открывают по порядку стремление, склонности словами и черты («сильно / заметно / слабо»); решения в деле открывают склонности без разговоров. Скрытые черты («Хитрый», «Злопамятный») выдаёт только поступок; скрытный в первом разговоре о главном молчит, но сразу рассказывает о стремлении. Годность к должности — словом, мнение главного — с пристрастием. «Взгляд дизайнера» показывает настоящие числа. Последней темой разговора человек рассказывает о связях: кто за него стоит, с кем он ладит и на кого в обиде.
- **Черты в течение жизни**: к ключевой черте человек наживает до трёх — из привычки («Прижимистый», «Сердобольный», «Чтит старину»), из отношений («Злопамятный к …» после саботажа); должностные черты («Мастер своего дела», «Оброс связями», «Устал от службы») в этот предел не входят и снимаются через сезон после ухода с должности; новая черта видна сразу, кроме скрытых; перелом («Ожесточился», «Стал набожен») — заготовка без событий-поводов.
- **Должность и характер**: у каждой должности 2–3 родные склонности — её события задевают их часто, остальные изредка; на своём месте человек решает по-своему в четырёх случаях из пяти, на чужом — меньше чем в половине. 38 событий совета; у каждой склонности есть цена, лес больше не копит одни плюсы. Таблицы — `npm run axes`.
- **Генератор натур** (отдельно от совета, в игру пока не подключён): 12 признаков, 30 натур, мешок из 131 черты и перка. У человека 1–2 врождённые черты, 2–6 нажитых до игры (по событиям предыстории, с возрастом больше) и нажитые в игре по поводам; четыре пятых его черт — нажитые. Отчёт `npm run natura`: рероллы одной натуры похожи на 0,08, натура угадывается по признакам в 91% случаев.
- **Портрет по Концепту 3** (в эмуляторе натуры, к совету пока не подключён): у человека видно, чего он хочет и что его удерживает, чем его взять и чем нельзя, что и как долго помнит, как говорит и как искажает доклад, с кем ладит и чем виден со стороны, какие нити судьбы открывает и где его дело идёт лучше. Складывается из двенадцати признаков и особенного 131 черты и перка мешка; у каждой строки видно, от признака она или от какой черты.
- **Здоровье** (отдельно от совета, в игру пока не подключено): крепость при рождении, 21 черта здоровья — врождённые, наследственные и нажитые, проверка каждый сезон. Срок жизни обычный: старость с 50 лет, предел около 85, половина взрослых доживает до 65, до 80 — единицы (3%). За 20 лет партии выбывает 57% людей (из тех, кому на начало 18–50, — 29%). Отчёт `npm run health`, раздел «Здоровье» в эмуляторе.
- **Мешки имён**: основа (90 мужских и 66 женских имён), славянский оттенок крестьян марок, прозвища и мешки пяти народов; генератор имени не даёт тёзок в одном месте и поколении, а когда мешок вычерпан — различает человека по мужу, по отцу или прозвищем. Люди прототипа названы именами из мешков (Гарвин, Добрава, Дестан…). К партии генератор пока не подключён.
- **Эмулятор натуры** — вторая страница, `dist/natura.html` (ссылка «Эмулятор натуры →» в шапке прототипа): прогон рероллов, метрики с целями, цветные графики, человек с древом черт, таблицы всего наполнения (натуры, мешок, признаки) и ручки, которые действуют сразу.
- **Хозяйство и подать**: четыре категории — люди (руки на сезон), еда, товары, серебро; шесть сторон с зонами доверия «заодно / ладят / терпят / отказывают» (деревень две: у брода и у опушки, у каждой свой староста), зона режет поток стороны. Год по сезонам: посевная, жатва и оброк осенью, прокорм (зимой вдвое), пошлины, жалованье, порча. Каждый поток ведёт держатель должности: с огоньком, как велено, без огонька или по-своему. Ведомость прошлого сезона построчно (по наведению на полосу), прогноз вилкой — тем шире, чем хуже счетовод; вороватый писарь прячет строку. Нижние черты еды и серебра, недодача и очередь «кого кормим первым». Курс на сезон (шесть курсов, со второго сезона сильнее). Подать: урок в мерах (испытание — 5 в год три года, потом 3), одиннадцать способов закрыть его «чем и с кого», сборщица осенью, недоимка с надбавкой, терпение Герцога.
- **Авторитет** не только тратится: опора каждый сезон (стороны в «ладят» и «заодно», признанный главный без вражды в совете, терпение Герцога), потолок 15 — излишек сгорает. Прибавки и потери: подать в срок или недоимка; жалобы — дела на столе (суд лично; не разобранная за год — потеря); обычаи и пиры за еду или серебро; дело сезона с советом советника — приказ против его мнения («оказался прав» или нет). Вместо снятия за авторитет человека можно уговорить уйти разговорами. Ниже нуля авторитет не уходит; ниже 5 слово весит меньше — каждая трата дороже на 1, а на что не хватает, то недоступно. Жалоба ждёт разбора год. Ведомость авторитета — на «Столе Сенешаля».
- **Эмулятор**: страница разбита на вкладки «Совет и люди», «Хозяйство и подать» и «Мир», справа всегда сводка (запасы сейчас, прошлый сезон, прогноз) и летопись. Панель ручек баланса (Tab): все числа совета, хозяйства и авторитета ползунками по разделам, изменённые подсвечены, два набора «было / стало» (1 / 2), «Сброс», «Выгрузить» (P) — текст изменённых значений для чата. Девять заготовок ситуаций (враги в совете, пустая должность, пустой амбар, вороватый писарь, недоимка и терпение на исходе и другие). Клавиши: пробел — сезон, F — пять, R — заново, D — взгляд дизайнера. Адрес страницы помнит семя, заготовку и галочки. Во «Взгляде дизайнера» у каждого решения в летописи — веса вариантов.
- **Боты**: привычки игрока, которые играют сотни партий без экрана. Три уровня: «Ничего не трогает» (совет сам, плюс девять заготовок), «Оставил порядок» (подготовил совет и уехал, пары О1–О6), «Хозяин» (тратит личные дела и авторитет, пары Х1–Х16), и «Случайный». Пары различаются одним решением и сравниваются на одних семенах: если ничего не расходится — решение пустое. Первые итоги — в `docs/design/boty.md`, раздел 10; перепроверки (наказ, знание о людях, подать, пиры, нижние черты, споры) — раздел 12.
- **Бот-искатель** (`npm run seek`): сам ищет стратегии игрока — перебирает «Хозяина» с одной и двумя изменёнными привычками, пробует случайные и собирает лучшую по шагам. Отбирает на двадцати партиях, подтверждает на двухстах других и печатает то, что заметно лучше «Хозяина», и то, что даёт необычный исход.
- **Люди решают исходы**: поток сферы зависит от того, кто её ведёт, — мастерство (годность к должности) × опыт × настрой, от ×0,6 до ×1,5. У каждой склонности на каждой должности свой почерк (25 клеток): заботливый тиун бережёт деревни и собирает меньше оброка, долговой — наоборот; вторая сильная склонность даёт оттенок. Засидевшийся — сильный, но своевольный: почерк вдвое сильнее, курс его не зажигает. У событий есть осторожные и смелые варианты и вложения с отдачей через 2–3 сезона; исход спора меняет силу дела, слаженный совет ведёт дела двух сфер лучше. Событий 38, из них почти половина — дела двух сфер.
- **Порядок — шкала строгости**: не «хорошо ↔ плохо», а «вольно ↔ строго». Пять ступеней — Смута, Вольница, Тихо, Строгость, Твёрдая рука; каждый шаг от середины усиливает и плюсы, и минусы своего края: пошлины, цена товаров, доверие деревень, молва о людях, кражи. Шкала тянется к норме по шагу за сезон; норму задают стража, стиль десятника и курс. Страже можно велеть затянуть — каждый шаг дороже — или отпустить: бесплатно, но всплывает гниль, накопленная при строгой руке. Со «Строгости» дозор приносит удачи: пойман казнокрад, накрыто логово.
- **Кризисы сторон и падение**: деревня, купцы или люди замка три сезона подряд отказывают — кризис ложится на стол как дело сезона, совет выбирает выход, а после остаётся шрам (поток стороны ниже несколько сезонов). Баронство отдают другому, если терпение Герцога исчерпано, недоимка совпала с кризисом, два кризиса идут сразу или не закрыт внеочередной сбор. Игра на этом не кончается: Сенешаль остаётся «под чужой рукой» — барон со своей натурой приводит свиту на должности, задаёт курс, его двор ест, перестановки только с его согласия. Барона можно склонять, можно раскачивать против него стороны (заметит — опала), а если ничего не делать, лес выживет его за восемь сезонов.
- **Мир вокруг**: генератор событий мира от того же семени. Наверху — состояния герцогства на годы (война на юге, неурожай, мор, ярмарочный год, тихий лес — всего 13); они сдвигают урожай, пошлины, цену товаров и урок подати, шлют вниз отголоски и делают одни дела совета чаще, другие реже. Погода года — множитель урожая. **Указы Герцога** — разовые требования людей, зерна, постоя: лежат на столе Сенешаля и закрываются теми же способами «чем и с кого», что подать; не закрыл — закроет совет, не смог — терпение Герцога и двор. **Совет отвечает на беду**: у каждой беды и указа есть ответственная должность — годный держатель смягчает потерю, негодный усиливает, пустая должность хуже всего; почерк даёт способ ответа со своей ценой («Запас впрок», «Откуп у двора», «Деревни не обирает»). Бывают тяжёлые годы — засуха и градобой. Строка «Что в мире» вверху и вкладка «Мир»: что действует сейчас и лента на 50 сезонов по слоям. С И11б мир зацеплен за порядок и кризисы: на строгом краю порядка часть бед оборачивается удачей дозора, на вольном бьёт сильнее; пока идёт кризис стороны или Сенешаль под чужой рукой, вести и указы мягче; кризис бывает и у леса (нашествие тварей), и у двора («помощник» от Герцога).
- **Приключенцы** (галочка «Лабиринт открыт») — события, задевающие две сферы сразу.
- **Ручки баланса**: все числа совета лежат в `src/sim/balance.ts`, у каждого диапазон, шаг и подпись — заготовка под ползунки эмулятора.
- **Проверки**: тесты логики (одно семя — одна партия, перестановки, исходы споров), проверка прототипа в настоящем браузере, проверка на GitHub на каждый pull request.

## Как устроено
```
src/data/   — данные: оси, черты, метки, должности, стремления, предыстории, события, хозяйство (стороны, курсы, способы платить подать)
src/sim/    — ядро без экрана: council/ — совет (генерация, решения, спор, перестановки, знание о людях), season.ts — сезон, economy/ — хозяйство и подать, state.ts — состояние партии (типы и чтение), balance.ts — числа баланса, rng.ts — случайность с семенем
src/ui/     — страницы: council/ — прототип совета (панели, эмулятор, точка входа main.ts), natura.ts — эмулятор натуры
tools/      — сборка в один HTML, прогон без экрана, проверка длины строк
test/       — тесты логики и проверка в браузере (test/e2e/smoke.py)
dist/       — собранные страницы: index.html (прототип совета) и natura.html (эмулятор натуры)
docs/       — design/ (замысел, решения, очередь задач), ARCHITECTURE.md, TESTING.md
```
Зависимости идут в одну сторону: `src/ui` → `src/sim` → `src/data`. Подробно — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md); как проверять — [docs/TESTING.md](docs/TESTING.md); правила работы над проектом — [CLAUDE.md](CLAUDE.md).

## Команды
```
npm install
npm run check        # всё разом: типы, линтер, тесты, сборка — после любой правки
npm run build        # собрать dist/index.html (один файл, открывается в браузере)
npm test             # тесты логики
npm run lint         # линтер и длина строк
npm run e2e          # проверка собранного прототипа в браузере (нужны Python, пакет playwright и Chrome)
npm run e2e -- --list            # разделы браузерной проверки; npm run e2e -- staff — один раздел
npm run sim -- семя 12 [--log]   # прогнать 12 сезонов без экрана и вывести сводку
npm run health -- --people=3000 [--save] [--diff]    # отчёт о здоровье: кто выбывает за партию, срок жизни
npm run natura -- --rolls=1000 [--save] [--diff]   # отчёт генератора натур: метрики, предупреждения, пять примеров
npm run bots -- --seeds=100 [--level=4] [--pair=О3] [--lab] [--full]   # отчёт по ботам: таблицы, пары, пустые решения; уровень 4 — перепроверки
npm run seek -- [--random=300] [--top=6] [--no-pairs] [--full]         # бот-искатель: стратегии лучше «Хозяина» и необычные исходы (около трёх минут)
npm run balance -- --diff [--save]                  # снимок баланса: первые строки отчёта ботов и что изменилось
npm run economy -- --seeds=100 [--save] [--diff]    # отчёт о хозяйстве: закрыто ли испытание, чем и с кого платят, недодача
npm run axes                     # отчёт: должность × склонность по событиям, плюсы и минусы склонностей, прогон 20 семян
```
