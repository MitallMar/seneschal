# Сенешаль — прототип характеров и совета

Проверка главной системы Концепта 2 («Kingmaker наоборот»): читаются ли персонажи как личности, когда совет решает дела без Сенешаля.

## ▶ Играть

- **[Открыть в браузере](https://claude.ai/artifact/3UcEDZupDmeFqxN2gSGyh9)** — страница на claude.ai, видна только автору. Обновляется не сама: после задачи её перевыкладывает чат проекта.
- **[Скачать `index.html`](https://github.com/MitallMar/seneschal/raw/main/dist/index.html)** — всегда последняя сборка из `main`. Скачанный файл открывается двойным щелчком, сервер и сеть не нужны.
- [Файл на GitHub](dist/index.html) — там же кнопка «Download raw file».

## Что уже есть
- **Звезда склонностей** из пяти осей: Долг, Выгода, Забота, Дерзость, Обычай.
- **Прогон предыстории**: черта и метка заданы автором, звезда, биография, стремление и личные связи складываются из 6 случайных событий.
- **Совет** из пяти должностей (староста, десятник, ключник, писарь-казначей, лесничий), главный на время отлучки.
- **Отношения** между членами совета: «заодно / ладят / терпят / соперники / враги», исходы споров (сошлись, рассудил главный, компромисс, продавил, саботаж, жалоба).
- **Опыт** с потолком (новичок → освоился → мастер), **«засиделся»**, **стремления**, **перестановки за авторитет**, **наказ**, медленный **дрейф** характера.
- **Видимость**: звезда размыта, пока Сенешаль не поговорит с человеком. «Взгляд дизайнера» показывает настоящие числа.
- **Приключенцы** (галочка «Лабиринт открыт») — события, задевающие две сферы сразу.
- **Ручки баланса**: все числа совета лежат в `src/sim/balance.ts`, у каждого диапазон, шаг и подпись — заготовка под ползунки спортзала.
- **Проверки**: тесты логики (одно семя — одна партия, перестановки, исходы споров), проверка прототипа в настоящем браузере, проверка на GitHub на каждый pull request.

## Что будет дальше
Очередь задач — [docs/design/backlog.md](docs/design/backlog.md).
- **Спортзал совета** (И2): панель ручек баланса с «было / стало», заготовки ситуаций (враги в совете, засидевшийся писарь, пустая должность), горячие клавиши, веса вариантов у каждого решения во «Взгляде дизайнера».
- **Боты совета и скрипты баланса** (И3): привычки игрока как боты, таблицы по прогонам, поиск «пустых» решений, снимок баланса.
- **Ждёт решения автора** (Д1): должна ли каждая должность задевать все пять склонностей.
- Позже, когда появится игра, а не прототип: сохранения, режим мастера, сборка для тестеров.

## Как играть
Ссылки — в разделе «Играть» вверху. Из клона репозитория: открыть `dist/index.html` в браузере (двойным щелчком, сервер и сеть не нужны). Замысел игры — [docs/design/koncept-2.md](docs/design/koncept-2.md).

## Как устроено
```
src/data/   — данные: оси, черты, метки, должности, стремления, предыстории, события
src/sim/    — ядро без экрана: генерация, решения, совет, сезоны; balance.ts — числа баланса, rng.ts — случайность с семенем
src/ui/     — страница прототипа
tools/      — сборка в один HTML, прогон без экрана, проверка длины строк
test/       — тесты логики и проверка в браузере (test/e2e/smoke.py)
dist/       — собранный прототип: один файл index.html
docs/       — design/ (замысел, решения, очередь задач), ARCHITECTURE.md, TESTING.md
```
Зависимости идут в одну сторону: `src/ui` → `src/sim` → `src/data`. Подробно — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md); как проверять — [docs/TESTING.md](docs/TESTING.md); правила работы над проектом — [CLAUDE.md](CLAUDE.md).

## Команды
```
npm install
npm run check        # всё разом: типы, линтер, тесты, сборка — после любой правки
npm run build        # собрать dist/index.html (один файл, открывается в браузере)
npm test             # тесты логики
npm run lint         # линтер и длина строк
npm run e2e          # проверка собранного прототипа в браузере (нужны Python, пакет playwright и Chrome)
npm run e2e -- --list            # разделы браузерной проверки; npm run e2e -- staff — один раздел
npm run sim -- семя 12 [--log]   # прогнать 12 сезонов без экрана и вывести сводку
```
